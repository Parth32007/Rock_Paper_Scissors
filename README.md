# 🎮 Rock Paper Scissors Game

A full-stack Rock Paper Scissors web application built using Python, Flask, HTML, CSS, and JavaScript.

## 🚀 Features
- Interactive gameplay
- Flask backend
- Responsive UI
- Score tracking
- Database integration (coming soon)

## 🛠 Tech Stack
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
